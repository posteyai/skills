# Postey for Claude

Draft, schedule and publish social posts across X, LinkedIn, Instagram, TikTok, YouTube,
Threads, Bluesky, Facebook and Pinterest from Claude, through Postey's hosted MCP server.

- One caption per network, written to that network's real limits
- Validation and an optional virality review before anything goes out
- Nothing publishes or schedules until you approve the exact copy

## Install

In Claude, add **Postey** from the plugin directory, then sign in to Postey when Claude first
uses it. In Claude Code:

```
claude plugin marketplace add posteyai/skills
claude plugin install postey@postey-skills
```

That installs the full Postey skill, which also uploads local files from your computer.
